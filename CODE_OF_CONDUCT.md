# Code Of Conduct

NomadInbox welcomes contributors who want safer local email tooling for AI agents.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but make technical risks explicit.
- Keep discussion focused on the issue or pull request.
- Respect privacy boundaries around mailbox data, credentials, exports, and logs.
- Help new users reproduce issues with synthetic or redacted data when possible.

## Unacceptable Behavior

- Harassment, abuse, threats, or discriminatory language.
- Posting another person's private data, mailbox content, credentials, or tokens.
- Pressuring maintainers or users to bypass safety approvals.
- Submitting changes that intentionally hide risky mail mutations or data exfiltration.

## Enforcement

Maintainers may edit, hide, or remove comments, close issues, block users, or reject contributions that violate this code of conduct.

Security or privacy incidents should also follow [SECURITY.md](SECURITY.md).
