# NomadInbox Roadmap

This roadmap describes public product direction. It is not a promise of delivery dates.

## Working

- Windows local workspace bootstrap.
- NomadMail CLI service.
- NomadMail MCP service.
- Tray-owned loopback HTTP service.
- Compiled Windows tray client.
- Outlook Desktop profile path on Windows.
- Gmail API local auth/config path.
- Read-only EML, MBOX, and JSONL archive import.
- Local runtime backup and restore guidance.
- Safety gates for send and delete/trash actions.
- Agent handoff and cross-chat discovery prompts.

## Active Hardening

- Gmail API setup and refresh-token ergonomics.
- Multi-account status display in the tray.
- Public installer flow and release assets.
- Clean first-run experience for fresh clones.
- Public GitHub community files, CI, and issue templates.

## Planned

- More complete Outlook Graph setup path.
- macOS and Linux launcher guidance for non-Outlook-Desktop use.
- Richer local index and normalized provider raw-data retention.
- More sample workflows for agent platforms.
- Screenshots, demo GIFs, and public release notes.

## Not Planned For The Bootstrap

- Hosted SaaS mailbox storage.
- Committing mailbox runtime data to Git.
- Always-on sync by default.
- Permanent delete without explicit multi-step confirmation.
- Privileged Windows Service installation as the default path.
