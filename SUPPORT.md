# Support

Use the channel that matches the problem:

| Need | Where to go |
|---|---|
| Bug with a command, provider, tray, MCP, or installer | Open a GitHub issue with the bug template |
| Feature request or provider request | Open a GitHub issue with the feature template |
| Security or privacy concern | Follow [SECURITY.md](SECURITY.md) |
| Contributing code | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| Understanding product scope | Read [PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md) |
| Architecture or provider contracts | Read [ARCHITECTURE.md](docs/ARCHITECTURE.md) |

When asking for help, include:

- operating system
- PowerShell version
- Node version
- NomadInbox version from `VERSION`
- exact command run
- provider path involved
- whether this used live mailbox access or only synthetic/archive data

Do not paste OAuth tokens, token caches, full mailbox exports, private message bodies, or private screenshots into public issues.
